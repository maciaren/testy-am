# testy-am
Ćwiczenie testów na prawo jazdy kategorii AM

## Co to jest?
Prosta strona do uruchamiania lokalnie, ułatwijąca naukę do egzaminu teoretycznego na prawo jazdy kategorii AM

- oparta na kompletnym, oficjalnym zestawie pytań ze strony Ministerstrwa Infrastruktury (https://www.gov.pl/web/infrastruktura/prawo-jazdy)
- [zestaw pytań](https://www.gov.pl/pliki/mi/pytania_egzaminacyjne_na_prawo_jazdy_tlumaczenia_migowe_12_2025.zip)
- zestaw multimediów (zdjęcia, filmy) do pytań
  -  https://www.gov.pl/pliki/mi/pytania_egzaminacyjne_na_prawo_jazdy_tlumaczenia_migowe_12_2025.zip
  -  https://www.gov.pl/attachment/10d143bf-9e93-4d82-935d-48c89353d3ce
